# Amar Seva Aasharam - Cow Seva NGO

Amar Seva Aasharam is a Cow Seva NGO dedicated to rescue,
care and protection of cows.

## Our Work
- Rescue injured and abandoned cows
- Provide food, shelter and medical care
- Daily Gau Seva
